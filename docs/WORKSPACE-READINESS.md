# 工作台接续与发布验收（1.7.0）

## 日常操作

首页默认保留今日聚焦与实际在用的模块。点「展开全部模块与辅助卡片」可以恢复完整布局；入口不会删除、隐藏或移动模块数据。没有个人记录时，从「记下今天的一件事」开始，更多配置可后补。

换设备：在原设备偏好设置中查看云端版本，比较后保存快照；在另一设备登录同一私有站点，查看并载入。快照包含模块、记录、主题、首页偏好和 Agent 关联编号，不包含 Agent 原始日志。两台设备都编辑过时，由用户选择保留哪份，不自动合并。数量相同不代表内容相同，可先分别导出文件。

云端快照依赖已部署的接收服务和快照数据库表；本机开发代理也可验证相同接口。静态前端不会自行拥有云端存储。单快照最多 1.5 MB，历史保留最近 10 份。超限时使用文件迁移，不截断内容。

载入文件或云端快照前，应用保留最近一次替换前副本。副本写入失败、容量不足或另一窗口改变数据时停止替换。恢复副本可以下载后再导入；下载不自动改变当前内容。本机副本与日常数据仍位于同一浏览器，重要内容应额外保存文件备份。

## 已覆盖的验收层次

- 数据、组件、存储和权限回归：含版本冲突、并发首次保存、未知历史、损坏响应、字节上限、恢复副本失败。
- 临时 SQLite 与真实 HTTP：所有者鉴权、跨站拒绝、大于事件批次限制的快照。
- 两个独立浏览器：真实 API / 数据库接续、来源关联和刷新保留；未连接用户生产数据。
- Windows CI：安装包、生成 Hooks、MCP，以及快照 API 和跨进程队列传输。

## 仍需要实际环境的项目

1. 在用户 Windows / WSL 的真实 Codex、Claude Code 或 WorkBuddy 中发起一次无敏感内容的小任务，观察客户端是否触发回调或 MCP。自动化用的是合成输入，没有代替客户端账号、权限和配置。
2. 检查实际托管工程的 D1 迁移、所有者登录、可信身份头及平台服务访问凭据。只合入仓库不会部署站点。
3. 用已授权项目检查实际断网、重新联网、关闭客户端和重新启动后的记录情况；核对原始依据、去重及关联待办。

未实现：后台实时同步、多人协作、自动字段合并、WorkBuddy 桌面原生完成 Hook、真实工时统计。

D1 限制参考：[官方 Limits](https://developers.cloudflare.com/d1/platform/limits/)。
