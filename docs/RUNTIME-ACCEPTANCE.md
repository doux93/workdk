## 实测发现并修复

本机服务原先只信任 5173 来源。在文档约定的 4173 构建预览中，GET 读取快照正常，但浏览器 PUT 带上 Origin 后被拒绝，前端显示需要登录。

修复后明确支持两个本机端口；测试宿主可以明确传入其他来源。未移除 Origin 校验，未使用通配符，也未取消凭据要求。新增真实 HTTP 测试确认其他端口、相似恶意域名及匿名写入仍被拒绝。

浏览器回归改为测试生产构建，并新增文件备份、损坏文件和恢复副本的完整往返流程，防止只测试开发服务器而漏掉预览问题。当前自动检查规模为 133 项数据／服务／UI 测试及 19 项 Chromium 流程，具体运行结果见对应 PR 的 Actions。
