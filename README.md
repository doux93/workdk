# 一隅 · 个人工作台

把时间，留给重要的事。可自定义模块、替换模板和调整主题的个人日常工作台。

## 功能

- **首页模板**：从容日常、心流时刻、高效掌控。
- **模块模板**：列表、看板、日历、笔记、快捷入口；切换视图保留原有记录。
- **模块管理**：新增、改名、图标与颜色、自定义文本字段、排序、隐藏及删除。
- **记录管理**：新增、编辑、详情页、完成状态、优先级、日期时间、网址及自定义字段。
- **辅助功能**：全局搜索（Ctrl/Cmd + K）、模块内筛选、看板拖动、25 分钟专注计时。
- **三套主题**：晨间青绿、午后暖沙、静谧深夜；适配桌面和窄屏。
- **数据备份**：当前浏览器自动保存，完整 JSON 导出和恢复。

初次打开包含明确标注的示例内容。偏好设置可清空当前全部记录并保留模块结构，请先导出备份。

## 本地启动

需要 **Node.js 22.13 或更高版本**。

```bash
git clone https://github.com/doux93/workdk.git
cd workdk
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173**。Windows 也可双击 `start-windows.cmd`，首次安装依赖后自动打开浏览器。关闭命令窗口会停止服务。首次安装需要联网；运行时无需外部字体、图片、AI 服务或数据库。

## 构建与检查

```bash
npm test
npm run build
npm run preview
```

构建产物位于 `dist/`，可部署到静态网站服务。预览地址为 **http://127.0.0.1:4173**。请通过 HTTP 服务打开，不要双击 `dist/index.html`。

## 模块与页面

每个模块拥有稳定的 `id`、名称、描述、图标、颜色、视图、自定义字段和记录。新增模块后导航和首页卡片自动读取配置，无需创建独立网页文件。

| 页面 | 路由 |
| --- | --- |
| 首页 | `/#home` |
| 模板中心 | `/#templates` |
| 偏好设置 | `/#settings` |
| 模块 | `/#modules/{moduleId}` |
| 记录详情 | `/#modules/{moduleId}/items/{entryId}` |

Hash 路由支持普通静态托管与详情页刷新；改名或换模板不会改变模块或记录 ID。

增加页面模板：在 `src/workspace.ts` 扩展 `View` 和 `views`，在 `src/App.tsx` 的 `ModuleContent` 添加渲染方式，在 `src/styles.css` 添加样式。继续使用统一记录结构即可保留已有内容。

增加首页布局：扩展 `Workspace.layout`、模板中心配置与 `.layout-*` 样式。

## 项目结构

- `src/App.tsx`：页面框架、路由、首页、模块视图、表单、搜索与备份。
- `src/workspace.ts`：数据模型、模板注册表、示例数据、导入与网址校验。
- `src/styles.css`：主题、布局、模板与响应式样式。
- `tests/workspace.test.mjs`：备份完整性、异常输入、数据保留和网址检查。
- `start-windows.cmd`：Windows 启动入口。

## 当前边界

数据存储在当前浏览器的 localStorage，不自动跨设备同步。不同浏览器、域名、端口之间的数据独立；跨设备迁移请导出并恢复备份。清除站点数据会清除工作台记录。备份包含全部记录，请自行妥善保存。

自定义字段目前是文本字段；模板替换指内置布局和视图切换，不支持上传并执行任意模板代码。专注计时在页面刷新后重置。当前未连接邮箱、企业日历等服务，也不会执行本地程序或读取电脑目录。

本仓库仅包含应用源码和示例内容，不包含个人数据、访问凭据或在线站点身份配置。
