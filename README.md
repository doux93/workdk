# 一隅 · 个人工作台

把时间，留给重要的事。可自定义模块、替换模板和调整主题的个人日常工作台。

## 功能

- **首页模板**：从容日常、心流时刻、高效掌控。
- **模块模板**：列表、看板、日历、笔记、快捷入口；切换视图保留原有记录。
- **模块管理**：新增、改名、图标与颜色、文本/数字/选项/链接字段、排序、隐藏及删除。
- **记录管理**：新增、编辑、详情页、完成状态、优先级、日期时间、网址及自定义字段。
- **辅助功能**：全局搜索（Ctrl/Cmd + K）、模块内筛选、看板拖动、25 分钟专注计时。
- **三套主题**：晨间青绿、午后暖沙、静谧深夜；适配桌面和窄屏。
- **数据备份**：当前浏览器自动保存，完整 JSON 导出和恢复。

初次打开包含明确标注的示例内容。偏好设置可清理未修改的示例；你新增、编辑过或更改过状态的记录会保留。旧版本没有示例标记的记录也会保留，避免误删。

## 英语学习模板

打开「模板中心」，点击顶部「英语学习」或向下找到学习模板区域。选择「使用模板」后，可修改名称、字段、颜色及页面视图，再创建模块。

| 模板         | 默认视图 | 预设字段                                 |
| ------------ | -------- | ---------------------------------------- |
| 我的单词本   | 列表     | 中文释义、例句、熟悉程度、复习计划       |
| 英语每日打卡 | 日历     | 学习时长（分钟）、学习内容、今日收获     |
| 听力与精读   | 笔记     | 材料链接、关键表达、理解程度、下一步     |
| 口语练习计划 | 看板     | 练习场景、目标表达、录音链接、自评与改进 |

创建时可取消「附带学习示例」，从空白开始。示例仅在确认创建后加入工作台；后续编辑或更改状态会作为个人内容保留。可重复创建多份独立的学习模块，也可随时切换通用视图。录音链接用于保存你自己的外部录音地址，模板不提供录音、自动评分或提醒服务。

## 本地启动

需要 **Node.js 22.13 或更高版本**。

```bash
git clone https://github.com/doux93/workdk.git
cd workdk
npm ci
npm run dev
```

打开 **http://127.0.0.1:5173**。Windows 也可双击 `start-windows.cmd`，首次安装依赖后自动打开浏览器。关闭命令窗口会停止服务。首次安装需要联网；运行时无需外部字体、图片、AI 服务或数据库。

## 构建与检查

```bash
npm run check      # 数据测试 + 自动界面测试 + 数据量压测 + 构建
npm run test:ui    # 单独运行自动界面测试
npm run test:perf  # 单独运行数据量压测
npm run preview
```

构建产物位于 `dist/`，可部署到静态网站服务。预览地址为 **http://127.0.0.1:4173**。请通过 HTTP 服务打开，不要双击 `dist/index.html`。

## 模块与页面

每个模块拥有稳定的 `id`、名称、描述、图标、颜色、视图、自定义字段和记录。新增模块后导航和首页卡片自动读取配置，无需创建独立网页文件。

| 页面     | 路由                                   |
| -------- | -------------------------------------- |
| 首页     | `/#home`                               |
| 模板中心 | `/#templates`                          |
| 偏好设置 | `/#settings`                           |
| 模块     | `/#modules/{moduleId}`                 |
| 记录详情 | `/#modules/{moduleId}/items/{entryId}` |

Hash 路由支持普通静态托管与详情页刷新；改名或换模板不会改变模块或记录 ID。

增加页面模板：在 `src/workspace.ts` 扩展 `View` 和 `views`，在 `src/components/ModuleContent.tsx` 添加渲染方式，在 `src/styles.css` 添加样式。继续使用统一记录结构即可保留已有内容。

增加首页布局：扩展 `Workspace.layout`、`src/components/TemplateCenter.tsx` 和 `HomeDashboard.tsx`，以及 `.layout-*` 样式。

## 项目结构

- `src/App.tsx`：路由、工作台状态、保存与页面协调。
- `src/components/HomeDashboard.tsx`、`TemplateCenter.tsx`：首页与模板中心。
- `src/components/ModuleContent.tsx`：列表、看板、日历、笔记与链接视图；包含分页与分批显示。
- `src/components/ModuleEditor.tsx`、`RecordEditor.tsx`：模块配置与记录编辑。
- `src/components/Fields.tsx`：字段输入和展示；`SearchDialog.tsx`：独立的全局搜索。
- `src/components/shared.tsx`、`src/hooks/useDraftGuard.ts`：共享界面和未保存内容保护。
- `src/workspace.ts`：数据模型、模板、字段配置、备份与输入校验。
- `src/search.ts`：带结果上限的搜索与模块筛选。
- `tests/workspace.test.mjs`、`tests/ui/`：数据回归与自动界面测试。
- `scripts/benchmark.mjs`、`reports/performance-latest.json`：可复现压测与最近一次结果。
- `start-windows.cmd`：Windows 启动入口。

## 当前边界

数据存储在当前浏览器的 localStorage，不自动跨设备同步。不同浏览器、域名、端口之间的数据独立；跨设备迁移请导出并恢复备份。清除站点数据会清除工作台记录。检测到损坏或不兼容的存储时会暂停自动保存并保留原始文本，可下载原始数据或恢复有效备份。保存失败会持续提示，不会伪装成已保存。备份包含全部记录，请自行妥善保存。

自定义字段支持文本、数字、选项和链接；模板替换指内置布局和视图切换，不支持上传并执行任意模板代码。专注计时在页面刷新后重置。当前未连接邮箱、企业日历等服务，也不会执行本地程序或读取电脑目录。

本仓库仅包含应用源码和示例内容，不包含个人数据、访问凭据或在线站点身份配置。

## 字段与维护升级（1.3.0）

「模块设置 → 字段类型设置」可以修改字段类型、数字单位和选项列表。英语学习模板默认将学习时长设为数字、熟悉程度和理解程度设为选项、材料与录音地址设为链接。旧模块也能使用相应控件；已有自由文本和自定义等级会保留。

列表每页显示 50 条；看板每列先显示 30 条；笔记和入口分批显示；全局搜索先显示 30 条匹配内容，继续补充关键词即可缩小范围。分页与分批显示不会删除或截断数据。

当前包含 17 项数据测试和 12 项自动界面测试，压测覆盖 1,000 / 5,000 / 10,000 条合成记录。[查看测试与性能说明](docs/TESTING.md)。
